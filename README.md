# AI 인프라 투자, 회수는 가능한가

능력의 확산, 가격의 붕괴, 그리고 비대칭 투자에 관한 공개 정보 기반 분석 노트입니다.

- 게시 페이지: https://lifegameshots.github.io/ai-infra-return-debate/
- 작성일: 2026-10-19
- 형식: 단일 HTML 문서 (`index.html`), GitHub Pages로 게시

## 다루는 내용

1. 세 개의 시계: 능력, 매출, 자본
2. 회수 계산: 캐펙스는 언제 돌아오는가 (상각 기간별 필요 수익률)
3. 부채의 층위와 자기자본 조달
4. 가격 디플레이션과 토큰당 원가 (DeepSeek 공식 가격표)
5. 중국 칩과 메모리: DeepSeek 릴리스 타임라인, 화웨이 어센드, GLM/「Ox Alpha」, CXMT
6. 능력의 깔때기와 지출의 깔때기 (Karpathy 정리)
7. 투자 원칙: 비대칭성과 확인 지표
8. 반론과 한계

## 주의

이 문서는 투자 권유가 아닙니다. 공개 정보와 공개 가격표, 보도 자료를 정리한 것이며, 인용한 제3자 리포트의 수치는 원문 공시로 독립 검증하지 않았습니다. 시장 가격과 정책은 빠르게 변합니다.
